# AGENTS.md

## Quick Commands

```bash
# Install all system deps + create venv
./setup.sh

# Check environment (no install)
./setup.sh --check

# GTK4 GUI launcher (recommended entry point)
./gui.py

# Run host server (bundled venv + bundled GStreamer runtime)
host/run.sh --output HEADLESS-2 --resolution 1080p --fps 60 --adb auto --debug

# Run host server (direct, skips bundled GStreamer — needs system GStreamer)
cd host && python -m psp_host --output VIRTUAL1 --resolution 1080p --fps 60

# Interactive management menu (start/stop/virtual display/status/build APK)
./start.sh

# Build Android APK (needs JDK 17 + Android SDK)
cd android && ./gradlew assembleDebug --no-daemon

# Run protocol unit tests (17 tests, no GStreamer needed)
python3 -m unittest tests.test_protocol -v

# CI-equivalent Python checks (flake8/mypy are advisory in CI, not gating)
python3 -m flake8 --max-line-length=127 --max-complexity=15 host/psp_host/ gui.py
python3 -m mypy --ignore-missing-imports --follow-imports=skip host/psp_host/

# Pre-commit (the ACTUAL enforced toolchain: ruff + black + isort + bandit + codespell)
pre-commit run --all-files

# Release: tag triggers Actions → 3-platform artifacts (Linux AppImage / Windows zip / Android APK)
git tag v0.x.0 && git push origin v0.x.0
```

## Architecture

- **Host** (`host/psp_host/`): Python package, entry via `python -m psp_host`. GStreamer pipeline captures screen, encodes H.264/VP9/VP8, streams over TCP.
- **Android** (`android/app/`): Kotlin app, receives TCP stream, decodes via MediaCodec, renders to surface. Touch input sent back as normalized (0..1) coordinates.
- **Protocol** (`docs/PROTOCOL.md`): TCP port 4747. Binary frames (4-byte LE length + flags + payload). JSON handshake negotiates codec/resolution/fps. Flags: bit0=keyframe, bit1=config, bit2=drop, bit7=control.
- **Scripts** (`scripts/`, `host/scripts/`): ADB USB setup, virtual display creation.
- **GUI** (`host/psp_host/gui.py`, `gui.py`): GTK4 多标签控制台。`gui.py` 是跨平台启动器（选 venv + 注入 runtime 环境变量 + `execvpe` 到 `python -m psp_host --gui`）。GUI 五个标签：服务（配置/启停/实时日志/运行统计）、状态、设备扫描、显示器（Hyprland HEADLESS 增删）、工具箱。服务以子进程 `host/run.sh` 运行，与 CLI/start.sh 行为一致。
  - **显示模式选择器**（服务标签）：`扩展模式`（默认，创建虚拟屏）/ `镜像模式`（不创建虚拟屏，捕获主屏内容）。
    - 镜像模式 X11：调 `vdisplay.get_primary_geometry()` 获取主屏 geometry → 生成 `--region`
    - 镜像模式 Wayland：获取不到主屏区域时回退 `--fullscreen`（Portal ScreenCast 让用户选主屏）
    - 镜像模式时虚拟屏相关控件全部隐藏
  - **捕获模式选择器**（服务标签，扩展模式下生效）：四个模式互斥，对应 CLI 的 `--output`/`--region`/`--fullscreen`：
    - `自动创建虚拟屏`（默认）— 无指定输出时调 `hyprctl output create headless` 建虚拟屏，失败回退主屏
    - `指定输出` — 从下拉选已有输出（X11 名或 HEADLESS-N）
    - `捕获区域` — 输入 `x,y,WxH`（如 `1920,0,1920x1080`），对应 `--region`
    - `全屏捕获` — 对应 `--fullscreen`，README 标注"不推荐"
  - 模式切换时动态显示/隐藏对应控件（`_on_capture_mode_changed`，同时响应捕获模式和显示模式）。
  - `--adb-path`、`--display`、`--selftest` 目前仅在 CLI 可用，GUI 未暴露。

## Development Facts

- **Two toolchains, don't confuse them**:
  - **Pre-commit** (`.pre-commit-config.yaml`): ruff + black + isort (line-length=127), bandit, codespell, shellcheck, markdownlint. This is the locally-enforced standard. Install: `pip install pre-commit && pre-commit install`.
  - **CI** (`.github/workflows/`): flake8 + mypy, but both are `continue-on-error: true` (advisory, non-gating). Only `py_compile` + `unittest` + the `E9,F63,F7,F82` flake8 selector are gating in `integration-ci.yml`.
- **Python version discrepancy**: shipped `host/venv/` targets Python 3.14.4, but CI matrix tests 3.10–3.13. Code must run on 3.10+; don't use 3.14-only syntax. The venv uses `--system-site-packages` (to access system `gi`/PyGObject) and is rebuilt by `./setup.sh`.
- **Repo hygiene is enforced**: `integration-ci.yml` rejects hardcoded `home/silver` paths and `pdb` remnants in `host/psp_host/` and `gui.py`. Don't add absolute user paths to those files.
- **`android/local.properties`**: tracked with hardcoded `sdk.dir=/home/silver/Android/Sdk`. Don't rely on it for portable builds.
- **`host/run.sh` vs direct `python -m psp_host`**: run.sh sets `LD_LIBRARY_PATH`, `GST_PLUGIN_PATH`, `GI_TYPELIB_PATH` for bundled runtime (`host/runtime/`). Direct invocation skips bundled GStreamer and needs system GStreamer.
- **`host/runtime/`**: generated by `host/bundle_runtime.sh`, bundles GStreamer libs. Optional — falls back to system GStreamer. Hardcodes Python 3.14 path.
- **Android build**: requires JDK 17, Android SDK. `ANDROID_HOME` and `JAVA_HOME` env vars used by `start.sh`. Default `JAVA_HOME` is `/usr/lib/jvm/zulu-17-amd64` (Zulu JDK 17, not OpenJDK path).
- **Default port**: 4747 (TCP stream). Discovery uses UDP port 4748 (only one PSP server per LAN segment).
- **Encoder priority**: x264enc > nvh264enc > vaapih264enc > vp9enc > vp8enc (auto-detected). Codec negotiation always returns H.264 regardless of client request.
- **Resolutions**: 720p (1280x720), 750p (1280x750), 1080p (1920x1080), 2K (2560x1440). Must stay even-aligned (H.264/I420).
- **FPS options**: 60, 90, 120, 144. Client sending `fps=0` means "unlimited" (server uses its max).
- **Android minSdk**: 26 (Android 8.0+), ARM-only (arm64-v8a, armeabi-v7a).
- **Wayland**: needs pipewiresrc + portal backend (hyprland/gnome/kde). X11 uses ximagesrc. GNOME Wayland may need EVDI kernel module for virtual display.
- **`input` group**: Linux input injection (`evdev` uinput) requires user in `input` group. `setup.sh` adds it but reboot is required. Without it, mouse button/scroll events silently fail.
- **`start.sh`**: Hyprland-specific. Uses `hyprctl` for virtual display management. Other compositors get no-ops.
- **Keyboard input**: Protocol documents `key` input events but host silently drops them (not implemented).
- **Frame queue**: maxsize=3, non-keyframes dropped when full, keyframes flush queue. Frame drops are by design.
- **Android touch**: short tap = left click (btn=1), 500ms long-press = right click (btn=2).
- **Tests**: `tests/test_protocol.py` is the only test suite (17 tests). It inserts `host/` into `sys.path` so `psp_host` imports resolve without `PYTHONPATH` when run from repo root. Integration CI runs the same suite from `host/` with `PYTHONPATH=.`.
- **`--selftest`**: packaging builds (`host/packaging/`) run a `--selftest` smoke check (GTK4/GStreamer/encoder/protocol) before publishing; release fails if selftest fails.
